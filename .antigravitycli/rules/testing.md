# Testing & Verification

## Automated Tests
- Run `npm test` inside the `7_Testing_Known/` directory to execute all link check and logic validations.
- **Test Scripts**:
  - `test_links.js`: Verifies public GitHub Pages and Azure Blob Storage URLs.
  - `test_logic.js`: Verifies the navigation menu and question data structures.

## Manual & Pre-commit Validation
- Always validate the syntax of any Mermaid charts before committing.
- Verify responsive styling behavior across different device widths and standard breakpoints.
