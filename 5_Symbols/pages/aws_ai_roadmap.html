AIF-C01 — AI Practitioner MLS-C01 — ML Specialty

🎯 Why AWS AI Certifications

AWS holds the largest share of the enterprise cloud market. AWS AI/ML certifications prove you can build, deploy, and operate intelligent applications on the world's most widely adopted cloud platform — from beginner AI concepts through expert-level ML engineering.

Two tracks: AI Practitioner (concepts, services, responsible AI) and ML Specialty (hands-on model building, feature engineering, MLOps on SageMaker).

🧩 AI Practitioner (AIF-C01) — Core Domains

🤖

AI & ML Fundamentals

Core concepts: supervised/unsupervised learning, neural networks, LLMs, generative AI basics.

  • Training vs inference
  • Model evaluation metrics
  • Foundation models
☁️

AWS AI/ML Services

Breadth of managed services: Rekognition, Comprehend, Textract, Polly, Translate, Lex, Kendra.

  • Choose right service per use-case
  • API-level integration
  • Pricing models
🧠

Generative AI on AWS

Amazon Bedrock, foundation model selection, prompt engineering, RAG patterns, agents.

  • Bedrock model catalogue
  • Knowledge bases (RAG)
  • Bedrock Agents
🛡️

Responsible AI

Bias, fairness, explainability, and AWS governance tools like SageMaker Clarify.

  • Model bias detection
  • SHAP explainability
  • AI governance frameworks

🧩 ML Specialty (MLS-C01) — Core Domains

📦

Data Engineering

S3 data lakes, Glue ETL, feature stores, data pipelines for ML at scale.

  • SageMaker Feature Store
  • AWS Glue & Athena
  • Kinesis for streaming ML
🔍

Exploratory Data Analysis

Statistical analysis, data cleaning, visualisation, and feature engineering techniques.

  • SageMaker Data Wrangler
  • Feature selection & encoding
  • Handling imbalanced datasets
🏋️

Modelling

Built-in SageMaker algorithms, custom training jobs, hyperparameter tuning.

  • XGBoost, Linear Learner, DeepAR
  • SageMaker Experiments
  • Automatic Model Tuning (AMT)
🚀

ML Implementation & Operations

Model deployment, A/B testing, monitoring drift, and MLOps pipelines.

  • SageMaker Endpoints
  • Model Monitor
  • SageMaker Pipelines (MLOps)
